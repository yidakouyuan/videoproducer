# 数据类型

## 2.1 通用基础枚举

```python
from dataclasses import dataclass, field
from typing import Optional, Literal, Any, Dict, List

Platform = Literal[
    "douyin",
    "xiaohongshu",
    "weibo",
    "bilibili",
    "youtube",
    "other",
]

SourceType = Literal[
    "post",
    "video",
    "note",
    "article",
    "image_post",
    "other",
]

MediaType = Literal[
    "video",
    "audio",
    "image",
    "text",
    "other",
]

AnalysisType = Literal[
    "video_understanding",
    "transcription",
    "image_understanding",
    "ocr",
    "music_identification",
    "other",
]

JobStatus = Literal[
    "queued",
    "running",
    "done",
    "failed",
    "partial",
    "cancelled",
]

SourceQuality = Literal[
    "high",
    "medium",
    "low",
]

```

## 2.2 用户任务相关

### `CreativeBrief`

系统内部统一任务描述。

```python
@dataclass
class CreativeBrief:
    user_query: str
    theme: Optional[str] = None
    audience: Optional[str] = None
    duration_sec: Optional[int] = None
    style: Optional[str] = None
    lang: str = "zh"
    publish_required: bool = False
    constraints: Dict[str, Any] = field(default_factory=dict)
    extra: Dict[str, Any] = field(default_factory=dict)
```

---

### `InputMaterial`

统一一条输入素材。

```python
@dataclass
class InputMaterial:
    material_type: MediaType | Literal["link"]
    text: Optional[str] = None
    source_ref: Optional["ContentRef"] = None
    media_id: Optional[str] = None
    url: Optional[str] = None
    extra: Dict[str, Any] = field(default_factory=dict)
```

---

### `InputMaterialSet`

统一一组输入素材。

```python
@dataclass
class InputMaterialSet:
    materials: List[InputMaterial] = field(default_factory=list)
```

## 2.3 平台内容引用相关

### `ContentRef`

通用“平台内容引用”。

```python
@dataclass
class ContentRef:
    platform: Platform
    source_type: SourceType
    source_id: str
    source_url: str
    author_id: Optional[str] = None
    author_name: Optional[str] = None
    title: Optional[str] = None
    extra: Dict[str, Any] = field(default_factory=dict)
```

> 这个类是最重要的之一。
> 
> 
> 以后无论抖音、小红书、微博，先统一落到它。
> 

---

### `VideoCandidate`

搜索阶段的候选视频对象。

```python
@dataclass
class Stats:
    digg: Optional[int] = None
    collect: Optional[int] = None
    comment: Optional[int] = None
    share: Optional[int] = None
    extra: Dict[str, Any] = field(default_factory=dict)
    
@dataclass
class CoverImage:
    url: str
    width: Optional[int] = None
    height: Optional[int] = None

@dataclass
class AuthorInfo:
    author_id: Optional[str] = None
    author_name: Optional[str] = None
    extra: Dict[str, Any] = field(default_factory=dict)

@dataclass
class VideoCandidate:
    content_ref: ContentRef
    title: str
    stats: Stats = field(default_factory=Stats)
    tags: List[str] = field(default_factory=list)
    cover_image: Optional[CoverImage] = None
    author: Optional[AuthorInfo] = None
    extra: Dict[str, Any] = field(default_factory=dict)
```

## 2.4 媒体解析与缓存相关

### `ResolvedMediaRef`

从平台内容解析出的正式媒体引用。

```python
@dataclass
class ResolvedMediaRef:
    content_ref: ContentRef
    media_type: MediaType
    media_url: Optional[str] = None
    downloadable: bool = False
    mime_type: Optional[str] = None
    extra: Dict[str, Any] = field(default_factory=dict)
```

> 这层的意义是：
> 
> 
> “这个内容已经被解析成媒体地址了，但还没被系统正式接管。”
> 

---

### `StorageInfo`

系统内部存储信息。

```python
@dataclass
class StorageInfo:
    local_path: Optional[str] = None
    object_url: Optional[str] = None
    extra: Dict[str, Any] = field(default_factory=dict)
```

---

### `StoredMedia`

系统已下载/缓存的稳定媒体对象。

```python
@dataclass
class StoredMedia:
    media_id: str
    content_ref: ContentRef
    media_type: MediaType
    storage: StorageInfo
    duration_sec: Optional[float] = None
    mime_type: Optional[str] = None
    file_size_bytes: Optional[int] = None
    extra: Dict[str, Any] = field(default_factory=dict)
```

> 后续分析服务应该尽量只吃这个对象，或者至少吃它的 `media_id`。
>

## 2. `POST /media/resolve_video`

### 用途

根据平台内容引用（当前是抖音视频）解析出正式的 `video_url`，并判断是否可下载。

### 输入

```json
{
  "source_ref": {
    "platform": "douyin",
    "aweme_id": "7611467221630662638",
    "share_url": "https://www.douyin.com/video/7611467221630662638"
  }
}
```

### 输出

```json
{
  "ok": true,
  "data": {
    "platform": "douyin",
    "aweme_id": "7611467221630662638",
    "share_url": "https://www.douyin.com/video/7611467221630662638",
    "video_url": "https://v3-dy-....mp4",
    "downloadable": true
  },
  "meta": {
    "request_id": "req_xxx",
    "elapsed_ms": 320
  }
}
```

### 失败示例

```json
{
  "ok": false,
  "error": {
    "code": "NOT_FOUND",
    "message": "unable to resolve downloadable video_url"
  },
  "meta": {
    "request_id": "req_xxx"
  }
}
```

## 11. `POST /media/cleanup`

### 用途

按条件批量清理缓存视频，防止长期占用空间。

### 输入

```json
{
  "older_than_days": 7,
  "only_unreferenced": true,
  "limit": 100,
  "dry_run": true
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `older_than_days` | integer | 否 | 删除多少天前的媒体 |
| `only_unreferenced` | boolean | 否 | 只清理未被引用的媒体 |
| `limit` | integer | 否 | 单次最多处理数量 |
| `dry_run` | boolean | 否 | 只预览，不真正删除 |

### 输出

```json
{
  "ok": true,
  "data": {
    "dry_run": true,
    "matched_count": 42,
    "deleted_count": 0,
    "candidates": [
      {
        "media_id": "md_001",
        "local_video_path": "/data/videos/md_001.mp4",
        "size_bytes": 12503456
      }
    ]
  },
  "meta": {
    "request_id": "req_xxx"
  }
}
```

### 说明

推荐默认先用 `dry_run=true`，避免误删。

# 三、建议保留的统一响应格式

所有接口统一采用：

## 成功

```json
{
  "ok": true,
  "data": {},
  "meta": {
    "request_id": "req_xxx",
    "elapsed_ms": 123
  }
}
```

## 失败
