# 模块一：抖音开放 API 可行性结论（2026-02-28）

## 结论（先给结果）

1. 直接用开放 API 获取“抖音官方热榜榜单”当前不可行（未找到公开热榜榜单接口）。
2. 可行的是“关键词视频搜索”能力，可拉取公开视频搜索结果，并离线入库。
3. 因此第一版建议定义为：`热榜方向的关键词离线库`，不是`官方热榜镜像库`。

## 已确认可用的官方能力

### 1) 抖音视频搜索（OpenAPI）

- 接口：`GET /dy_open_api/v2/search/video/`
- 用途：按关键词返回视频列表
- 关键参数：`keyword`、`count`（最大 50）、`cursor`、`device_id`
- 鉴权：`access-token`（由 `client_key/client_secret` 换取 `client_token`）
- 可拿到字段（典型）：视频 `aweme_id`、标题、发布时间、作者信息、封面/播放地址、互动统计（点赞/评论/播放/分享等）

### 2) 关键词视频管理（企业侧）

- 接口：`GET /video/search/`
- 用途：获取关键词匹配的视频结果（通常需关键词管理能力和审批）
- 限制特征：关键词有数量上限，结果通常偏向近期发布内容

## 与“热榜离线数据库”目标的差距

- 目前公开能力是“你给关键词 -> 返回视频”，不是“平台给当前热榜榜单”。
- 所以 API 路线能稳定构建的是：
  - 关键词维度的热视频池；
  - 可按时间跑批沉淀趋势；
  - 可做后续选题、脚本、视频生成的素材源。

## 第一版落地方案（已实现）

- 使用 `src/douyin_hot_db/collect_douyin_openapi.py`：
  1. 用 `client_key/client_secret` 获取 `client_token`
  2. 对 `keywords.txt` 中关键词分页拉取
  3. 写入 SQLite：
     - `videos`：视频主表（去重）
     - `video_snapshots`：采集快照（可做时序趋势）
     - `runs`：批次运行记录
     - `search_tasks`：关键词任务

## 风险与前置条件

1. 需要你在开放平台完成应用创建、能力申请与审核。  
2. 不同能力对应不同权限，未获权时会返回业务错误码。  
3. 本地当前运行环境无法直接连外网域名（DNS 受限），因此本次做的是“代码链路可运行+文档可核对”，真实接口联调需要你在可联网环境执行。
